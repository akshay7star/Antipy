# Django Templates

If you put a bunch of `<h1>` and `<div>` tags directly inside your Python `views.py` file, your code would quickly become an unreadable, tangled mess. 

Django's **Template System** separates your application's logic (Python) from its presentation (HTML). It allows you to pass variables from the database directly into your web pages, and construct reusable layouts.

## Connecting Views to Templates

In the previous lesson, we returned a simple string using `HttpResponse`. To use a template, we use the `render()` shortcut instead.

```python
from django.shortcuts import render

def profile_view(request):
    # This dictionary is called the "context"
    # It contains the variables we want to send to the HTML
    context = {
        'username': 'Alice',
        'account_balance': 250.50,
        'is_premium': True
    }
    
    # render() takes the request, the template name, and the context dictionary
    return render(request, 'profile.html', context)
```

## Template Syntax

Django has its own templating language (which heavily inspired Jinja2 in Flask). It uses specific syntax boundaries to distinguish HTML from dynamic content.

### 1. Variables: `{{ }}`
Double curly braces are used to output the value of a variable.

```html
<!-- Inside profile.html -->
<h1>Welcome back, {{ username }}!</h1>
<p>Your balance is: ${{ account_balance }}</p>
```

### 2. Tags (Logic): `{% %}`
Curly brace + percent sign is used for control flow, like loops and conditionals.

<interactive-code>
<!-- If / Else statements -->
{% if is_premium %}
    <span class="badge">Premium Member</span>
{% else %}
    <a href="/upgrade">Upgrade to Premium</a>
{% endif %}

<!-- For loops over lists -->
<ul>
{% for item in shopping_cart %}
    <li>{{ item.name }} - ${{ item.price }}</li>
{% empty %}
    <li>Your cart is empty!</li>
{% endfor %}
</ul>
</interactive-code>

### 3. Filters: `|`
Filters transform the value of a variable before it is displayed.

```html
<!-- Converts the string to lowercase -->
<p>User: {{ username|lower }}</p>

<!-- Formats a date object -->
<p>Joined: {{ join_date|date:"F j, Y" }}</p>

<!-- Truncates long text -->
<p>Bio: {{ biography|truncatewords:30 }}</p>
```

## Template Inheritance (The Best Feature)

The most powerful feature of Django templates is **inheritance**. It allows you to build a base "skeleton" template that contains your common elements (header, footer, CSS links) and define blocks that child templates can override.

### `base.html` (The Skeleton)

<interactive-code>
<!DOCTYPE html>
<html>
<head>
    <title>My Django Site</title>
    <!-- Link to static CSS files -->
    {% load static %}
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>
<body>
    <nav>
        <a href="{% url 'home' %}">Home</a>
    </nav>

    <div class="content">
        <!-- This is a hole that child templates will fill -->
        {% block main_content %}
        {% endblock %}
    </div>

    <footer>&copy; 2026</footer>
</body>
</html>
</interactive-code>

### `about.html` (The Child)

```html
<!-- Tell Django this template inherits from base.html -->
{% extends "base.html" %}

<!-- Fill in the hole defined in the parent! -->
{% block main_content %}
    <h1>About Us</h1>
    <p>We build great software.</p>
{% endblock %}
```

When Django renders `about.html`, it automatically wraps the `<h1>` and `<p>` tags inside the massive `base.html` layout!
