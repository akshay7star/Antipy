# Django Basics

If Flask is a lightweight sports car where you build your own dashboard, Django is a massive, fully-equipped luxury SUV. 

Django is a **"batteries-included"** framework. Out of the box, it provides a built-in SQL database ORM, an admin control panel, user authentication, session management, and robust security protections (like CSRF and XSS defense).

Because of its massive feature set, it powers some of the largest applications on the internet, including Instagram, Pinterest, and Spotify.

## The MTV Architecture

Most modern web frameworks follow the MVC (Model-View-Controller) architecture. Django uses a slight variation called **MTV**:
1. **M (Model):** Defines your data structure (the Database).
2. **T (Template):** Defines what the user sees (the HTML).
3. **V (View):** The brain. The Python function that grabs data from the Model and hands it to the Template.

## Creating a Django Project

Unlike Flask where you just create an `app.py` file, Django projects are generated using a command-line utility.

```bash
# 1. Install Django
$ pip install django

# 2. Create the massive project scaffold
$ django-admin startproject my_website
```

This generates a complex directory structure:
```text
my_website/
    manage.py       # The command-line utility for your project
    my_website/     # The project configuration folder
        settings.py # Master settings (Database info, installed apps)
        urls.py     # The master router
        wsgi.py     # Web server entry point
```

## Creating an "App"

A Django Project is composed of multiple smaller "Apps." Think of an App as a specific feature of your website. For example, Amazon might have a `cart` app, a `checkout` app, and an `inventory` app.

```bash
# Move into the project folder
$ cd my_website

# Create an app
$ python manage.py startapp blog
```

This creates a `blog/` directory with its own `models.py` (for the database) and `views.py` (for the logic). You must then register this new app inside your master `settings.py` file.

<interactive-code>
# Inside my_website/settings.py

INSTALLED_APPS = [
    # Built-in Django Apps
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    
    # Your Custom Apps!
    'blog',
]
</interactive-code>

## The Development Server

Django includes a robust local development server.

```bash
$ python manage.py runserver
```
Visiting `http://127.0.0.1:8000/` will show the famous Django rocket taking off, confirming your project is successfully configured!
