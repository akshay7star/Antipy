# The 0/1 Knapsack Problem

The Knapsack Problem is the foundational template for **resource-constrained optimization** in dynamic programming. Every real-world allocation problem — budget planning, memory packing, portfolio optimization — maps to this structure.

**Problem**: Given `n` items, each with a **weight** and **value**, and a knapsack with a maximum **capacity** W, find the maximum total value you can carry. Each item can be taken **at most once** (0/1 — either take it or don't).

## The 2D DP Table

`dp[i][w]` = maximum value using the first `i` items with capacity `w`.

```python
def knapsack_01(weights, values, W):
    n = len(weights)
    # dp[i][w] = max value with first i items, capacity w
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        weight_i = weights[i - 1]
        value_i  = values[i - 1]

        for w in range(W + 1):
            # Option 1: Skip item i (inherit from i-1 items)
            dp[i][w] = dp[i-1][w]

            # Option 2: Take item i (if it fits)
            if weight_i <= w:
                take = dp[i-1][w - weight_i] + value_i
                dp[i][w] = max(dp[i][w], take)

    return dp[n][W]
```

## The Recurrence Explained

```
dp[i][w] = max(
    dp[i-1][w],                          # Don't take item i
    dp[i-1][w - weight[i]] + value[i]   # Take item i
)

Base cases:
    dp[0][w] = 0  (no items → no value)
    dp[i][0] = 0  (no capacity → no value)
```

## Reconstructing Which Items Were Taken

```python
def knapsack_with_items(weights, values, W):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(W + 1):
            dp[i][w] = dp[i-1][w]
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i][w], dp[i-1][w-weights[i-1]] + values[i-1])

    # Backtrack to find chosen items
    chosen = []
    i, w = n, W
    while i > 0 and w > 0:
        if dp[i][w] != dp[i-1][w]:   # Item i was taken
            chosen.append(i - 1)     # 0-indexed
            w -= weights[i - 1]
        i -= 1

    return dp[n][W], list(reversed(chosen))
```

## Space Optimization: 1D DP

We only ever look at the previous row (`dp[i-1]`). Compress to 1D:

```python
def knapsack_1d(weights, values, W):
    dp = [0] * (W + 1)

    for i in range(len(weights)):
        # Traverse W DOWN to prevent using item i twice!
        for w in range(W, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])

    return dp[W]

# Why traverse in reverse?
# If we go left-to-right, dp[w-weight] might already include item i
# (since we updated it earlier in this same pass) → item counted twice!
# Reverse traversal ensures we only use each item once.
```

## Knapsack Variants

| Variant | Change | Solution |
|---|---|---|
| **0/1 Knapsack** | Each item taken 0 or 1 times | Reverse inner loop |
| **Unbounded Knapsack** | Each item taken unlimited times | Forward inner loop |
| **Subset Sum** | Can we reach exact weight W? | Boolean DP |
| **Partition Equal Subset** | Can we split into two equal-sum halves? | Subset Sum variant |

```python
# Unbounded Knapsack (infinite copies of each item)
def knapsack_unbounded(weights, values, W):
    dp = [0] * (W + 1)
    for w in range(W + 1):      # Forward — allows reuse!
        for i, (wi, vi) in enumerate(zip(weights, values)):
            if wi <= w:
                dp[w] = max(dp[w], dp[w - wi] + vi)
    return dp[W]

# Subset Sum (boolean variant — can we hit exactly target?)
def subset_sum(nums, target):
    dp = [False] * (target + 1)
    dp[0] = True
    for num in nums:
        for t in range(target, num - 1, -1):  # Reverse — each num used once
            dp[t] = dp[t] or dp[t - num]
    return dp[target]
```

> **Pro Tip:** The direction of the inner loop is the key to knapsack variants. **Reverse** (W down to weight) = 0/1 (each item once). **Forward** (weight up to W) = unbounded (items reused). This single change flips the entire problem variant.

> **Common Mistake:** Forgetting that knapsack's 2D table has `n+1` rows and `W+1` columns (1-indexed for items). Off-by-one errors here are common — `dp[i][w]` means "using items 1..i with capacity w", and `dp[0][*] = 0` is the "no items" base case.
