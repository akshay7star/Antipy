# BFS & DFS: Conquering Graphs

Graphs model everything: social networks, road maps, dependency trees, the web. Two algorithms dominate graph traversal: **Breadth-First Search** (explores level by level) and **Depth-First Search** (dives as deep as possible before backtracking).

## BFS: Breadth-First Search

Uses a **queue** (FIFO). Visits all nodes at distance 1, then distance 2, etc. Guarantees **shortest path** in unweighted graphs.

```python
from collections import deque

def bfs(graph, start):
    visited = set([start])
    queue = deque([start])
    order = []

    while queue:
        node = queue.popleft()    # FIFO
        order.append(node)

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return order

def bfs_shortest_path(graph, start, end):
    visited = {start}
    queue = deque([(start, [start])])  # (node, path_so_far)

    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None
```

## DFS: Depth-First Search

Uses a **stack** (explicit or recursive call stack). Dives deep before backtracking. Used for: cycle detection, topological sort, connected components, maze solving.

```python
# Recursive DFS
def dfs_recursive(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)

    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs_recursive(graph, neighbor, visited)

    return visited

# Iterative DFS (uses explicit stack)
def dfs_iterative(graph, start):
    visited = set()
    stack = [start]
    order = []

    while stack:
        node = stack.pop()     # LIFO (vs BFS which uses popleft)
        if node not in visited:
            visited.add(node)
            order.append(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    stack.append(neighbor)

    return order
```

## BFS on a Grid (Very Common in Interviews)

Many problems model grids as graphs (each cell is a node, adjacent cells are neighbors):

```python
def bfs_grid(grid, start_r, start_c, target_r, target_c):
    rows, cols = len(grid), len(grid[0])
    visited = set([(start_r, start_c)])
    queue = deque([(start_r, start_c, 0)])  # (row, col, distance)
    directions = [(0,1),(0,-1),(1,0),(-1,0)]  # Right, Left, Down, Up

    while queue:
        r, c, dist = queue.popleft()
        if r == target_r and c == target_c:
            return dist
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            if (0 <= nr < rows and 0 <= nc < cols
                    and grid[nr][nc] != '#'   # Not a wall
                    and (nr, nc) not in visited):
                visited.add((nr, nc))
                queue.append((nr, nc, dist + 1))

    return -1   # Unreachable
```

def bfs_shortest(graph, start, end):
    if start == end: return [start]
    visited = {start}
    queue = deque([(start, [start])])

        node, path = queue.popleft()
        for nb in graph[node]:

def has_cycle_directed(graph, n_nodes):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n_nodes

    def dfs_cycle(node):
        color[node] = GRAY
        for nb in graph[node]:
            if color[nb] == GRAY: return True   # Back edge = cycle
            if color[nb] == WHITE and dfs_cycle(nb): return True
        color[node] = BLACK
        return False

    return any(dfs_cycle(i) for i in range(n_nodes) if color[i] == WHITE)

## BFS vs DFS Decision Guide

| Use BFS when... | Use DFS when... |
|---|---|
| **Shortest path** in unweighted graph | **Cycle detection** |
| Finding nodes at distance k | **Topological sort** |
| Level-order traversal | Exploring all paths |
| Word ladder / grid problems | Maze solving (find any path) |
| Social network distance | **Connected components** |

> **Pro Tip:** In grid problems, BFS is almost always the answer for "minimum steps" or "shortest path." For "does a path exist" or "how many regions," DFS is simpler. Time complexity for both on adjacency list: O(V + E).

> **Common Mistake:** Not initializing `visited` before starting BFS/DFS, or adding to visited AFTER popping (instead of BEFORE enqueuing). Always add to visited when you first discover a node (before enqueuing) — otherwise you enqueue the same node multiple times.
