# LRU Cache: The O(1) Memory Manager

Every time Google Chrome fetches a webpage, every time a CDN serves an asset, every time a CPU retrieves data from RAM — a **cache** is involved. The most important cache eviction policy in systems is **LRU: Least Recently Used**.

When the cache is full and a new item arrives, the **least recently accessed** item is evicted to make room. This matches the **temporal locality** principle: data accessed recently is likely to be accessed again soon.

## The Design Constraint

- `get(key)` → O(1) — must be instant
- `put(key, value)` → O(1) — even when eviction is needed
- Both operations must update the "recently used" order

**Why is this hard?** O(1) lookup demands a hash map. But reordering by "recency" demands a data structure that supports O(1) move-to-front. A regular list is O(n) to reorder. The solution: **hash map + doubly linked list**.

## The Architecture

```python
class Node:
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {}          # key → Node (O(1) lookup)

        # Sentinel nodes: no boundary checks needed
        self.head = Node()       # Most recently used side
        self.tail = Node()       # Least recently used side
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        """Remove node from doubly linked list — O(1)"""
        node.prev.next = node.next
        node.next.prev = node.prev

    def _insert_front(self, node):
        """Insert node right after head (most recent position) — O(1)"""
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)       # Remove from current position
        self._insert_front(node) # Move to most-recent
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self._remove(self.cache[key])
        node = Node(key, value)
        self.cache[key] = node
        self._insert_front(node)

        if len(self.cache) > self.capacity:
            # Evict: remove from tail (least recently used)
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]
```

        self.cache = {}
        self.head = Node()  # Most recent sentinel
        self.tail = Node()  # Least recent sentinel
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _insert_front(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._insert_front(node)
        return node.val

    def put(self, key, value):

            self._remove(self.cache[key])
        node = Node(key, value)
        self.cache[key] = node
        self._insert_front(node)
        if len(self.cache) > self.capacity:
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]

    def state(self):
        order = []
        cur = self.head.next
        while cur != self.tail:
            order.append(f"({cur.key}:{cur.val})")
            cur = cur.next
        return "MRU → [" + ", ".join(order) + "] ← LRU"

from functools import lru_cache

@lru_cache(maxsize=8)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

import time
start = time.perf_counter()
result = fibonacci(40)
elapsed = (time.perf_counter() - start) * 1000
print(f"fibonacci(40) = {result} in {elapsed:.3f}ms (cached!)")
print(f"Cache info: {fibonacci.cache_info()}")

## Python's Built-in: `functools.lru_cache`

Python ships with a production-grade LRU cache as a decorator:

```python
from functools import lru_cache

@lru_cache(maxsize=128)   # Caches last 128 unique calls
def expensive_computation(n):
    # ... complex work ...
    return result

# Or as a class method alternative:
from functools import cached_property

class Circle:
    def __init__(self, r):
        self.r = r

    @cached_property   # Computed once, then cached forever
    def area(self):
        import math
        return math.pi * self.r ** 2
```

> **Pro Tip:** `@lru_cache` is the most underused optimization in Python. Any pure function (same input always gives same output) that's called repeatedly with the same arguments is a prime caching candidate. Time complexity drops from O(T) to O(1) for cached calls.

> **Common Mistake:** Using `@lru_cache` on methods that reference `self`. Since `self` becomes part of the cache key, it creates a reference cycle and prevents garbage collection. Use `@cached_property` for instance computations, or cache at the module level.
