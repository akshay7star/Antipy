# Templates (Jinja2)

Returning simple strings like `"Welcome!"` from a route is fine for APIs, but real web applications return massive, beautifully styled HTML files.

Writing raw HTML inside your Python strings is messy and unmaintainable. Instead, Flask handles this using a templating engine called **Jinja2**.

## `render_template`

To use templates, you create a folder named `templates` in the exact same directory as your Python script. Flask will automatically look for HTML files inside this folder.

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    # Flask looks for "index.html" inside the "templates" folder
    return render_template('index.html')
```

## Passing Variables to HTML

The true power of Jinja is that you can pass Python variables straight into the HTML structure.

Inside your Python file:
```python
@app.route('/profile')
def profile():
    user_name = "Alice"
    user_age = 28
    return render_template('profile.html', name=user_name, age=user_age)
```

Inside `templates/profile.html`:
```html
<!-- Jinja uses double curly braces to print variables -->
<h1>Welcome, {{ name }}!</h1>
<p>You are {{ age }} years old.</p>
```

When the user visits `/profile`, Jinja dynamically replaces `{{ name }}` with "Alice" and sends the fully rendered HTML string to the browser.

## Control Flow in HTML

Jinja doesn't just print variables; it lets you write python-like `if` statements and `for` loops *inside* your HTML layout!

### Loops

```html
<!-- This syntax uses {% %} for logic -->
<ul>
{% for item in cart_items %}
    <li>{{ item.name }} - ${{ item.price }}</li>
{% else %}
    <!-- The else block runs if the cart_items list is empty! -->
    <li>Your cart is empty!</li>
{% endfor %}
</ul>
```

### Conditionals

```html
{% if user.is_logged_in %}
    <button>Logout</button>
{% elif user.is_banned %}
    <p>Your account is locked.</p>
{% else %}
    <button>Login</button>
{% endif %}
```

## Template Inheritance

If your website has 50 pages, you absolutely do not want to copy and paste the `<nav>` bar and `<footer>` HTML into all 50 files! 

Jinja solves this elegantly with **Template Inheritance**. You create one "base" layout, and other templates "extend" it, filling in specific holes called blocks.

`base.html` (The Parent Layout):
```html
<html>
  <head>
    <title>My Cool App</title>
  </head>
  <body>
    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>
    
    <div class="main-content">
        <!-- Child templates will inject their HTML here -->
        {% block content %}
        {% endblock %}
    </div>
    
    <footer>Copyright 2026</footer>
  </body>
</html>
```

`about.html` (The Child Template):
```html
{% extends "base.html" %}

{% block content %}
  <h1>About Us</h1>
  <p>We are a cool company.</p>
{% endblock %}
```

When `render_template('about.html')` is called, Jinja loads `base.html`, rips out the `{% block content %}`, and replaces it with the `<h1>` and `<p>` from `about.html`.
