# Authentication in Flask

Building a website is easy; remembering who is visiting your website is hard. 

HTTP is a **stateless protocol**. Every time a user clicks a link, submits a form, or refreshes the page, their browser opens a brand-new connection to the server. The server has no memory of the previous request. 

So how do we build a "Login" system if the server forgets the user the moment the page finishes loading? We use **Sessions**.

## What is a Session?

A session is a mechanism that allows Flask to store information about a specific user across multiple requests. In Flask, the session data is encrypted and stored securely in a **cookie** inside the user's web browser.

Whenever the browser makes a new request, it automatically sends that cookie back to the server, allowing Flask to "remember" who the user is.

<interactive-code>
from flask import Flask, session, request

app = Flask(__name__)
# Flask MUST have a secret key to encrypt cookies!
app.secret_key = 'super_secret_password_do_not_share_in_production'

@app.route('/login')
def login():
    # Imagine we checked a database here to ensure the password is correct
    session['username'] = 'Alice'
    return "You are logged in! We saved your username in a signed cookie."

@app.route('/dashboard')
def dashboard():
    # We check if the browser sent back a cookie containing 'username'
    if 'username' in session:
        return f"Welcome back, {session['username']}!"
    
    return "Access Denied: Please log in."
</interactive-code>

### The Secret Key
Notice the `app.secret_key`. This is absolutely critical. Without a secret key, a malicious user could open their browser's developer tools, find the plain-text session cookie `{'username': 'Alice'}`, change it to `{'username': 'Admin'}`, and instantly hack your website.

By setting a secret key, Flask cryptographically signs the cookie. If the user tampers with the cookie, the signature becomes invalid, and Flask rejects the entire session.

## Logging Out

Logging out is delightfully simple: you just delete the user's data from the session dictionary. Next time their browser makes a request, the session will be empty, and the server will treat them as an anonymous visitor.

```python
@app.route('/logout')
def logout():
    # session.pop() removes the key safely without throwing an error if it doesn't exist
    session.pop('username', None)
    return "You have been successfully logged out."
```

## Passwords and Hashing

If a user signs up on your website, you **MUST NEVER** save their actual password to the database. If your server is ever compromised, the attackers would steal thousands of passwords (which users tragically reuse on their emails and bank accounts).

Instead, you save a mathematically mangled version of the password, called a **Hash**.

Fortunately, Werkzeug (the foundational toolkit Flask is built upon) provides secure hashing for free.

<interactive-code>
from werkzeug.security import generate_password_hash, check_password_hash

# 1. User signs up: "ilovecats123"
# We generate a hash and store THIS in the database.
stored_hash = generate_password_hash("ilovecats123")
print(f"What we store in the DB:\n{stored_hash}\n")

# 2. User tries to log in later with wrong password "ilovedogs123"
# We DO NOT decrypt the hash. We hash the attempt and compare them!
login_attempt1 = check_password_hash(stored_hash, "ilovedogs123")
print(f"Login attempt (wrong password): {login_attempt1}")

# 3. User tries again with correct password
login_attempt2 = check_password_hash(stored_hash, "ilovecats123")
print(f"Login attempt (correct password): {login_attempt2}")
</interactive-code>

## Flask-Login Extension

While you *can* write your own logic to check `if 'username' in session:` manually on every single secure page of your site, that gets tedious.

The widely popular external library `Flask-Login` handles all the heavy lifting for you, providing the powerful `@login_required` decorator.

```python
from flask import Flask
from flask_login import login_required

app = Flask(__name__)

@app.route('/settings')
@login_required  # Acts as a bouncer for this route
def secret_settings():
    return "Welcome to the secret vault."
```

If an anonymous user tries to visit `/settings`, Flask-Login intercepts the request and automatically redirects them to your login page.
