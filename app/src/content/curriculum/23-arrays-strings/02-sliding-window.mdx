# Sliding Window: The O(n) Subarray Weapon

<TwoPointersVisualizer />

The brute-force approach to any "find the best subarray" problem is two nested loops: O(n²). The **Sliding Window** technique converts this to O(n) by maintaining a window that **expands and contracts** in a single pass.

The core insight: instead of recomputing the window's value from scratch at every position, you **add the incoming element** and **remove the outgoing element** — incremental updates only.

## Fixed-Size Window

The simplest case: the window size `k` is given. Slide it from left to right.

```python
def max_sum_subarray(nums, k):
    # Initialize first window
    window_sum = sum(nums[:k])
    max_sum = window_sum

    # Slide: add nums[i], remove nums[i-k]
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]   # O(1) update!
        max_sum = max(max_sum, window_sum)

    return max_sum

# Brute force: O(n*k)    Sliding window: O(n)
print(max_sum_subarray([2, 1, 5, 1, 3, 2], 3))  # 9
```

## Dynamic-Size Window

The harder case: window size varies. Expand the right boundary, shrink the left when a constraint is violated.

```python
# Longest substring with at most k distinct characters
def longest_k_distinct(s, k):
    count = {}
    left = 0
    max_len = 0

    for right in range(len(s)):
        # Expand: add s[right] to window
        count[s[right]] = count.get(s[right], 0) + 1

        # Shrink: contract until constraint satisfied
        while len(count) > k:
            count[s[left]] -= 1
            if count[s[left]] == 0:
                del count[s[left]]
            left += 1

        max_len = max(max_len, right - left + 1)

    return max_len
```

## The Template: Dynamic Sliding Window

Master this pattern and you can solve 90% of sliding window problems:

```python
def sliding_window_template(arr, constraint):
    left = 0
    window_state = {}   # Track what's in the window
    best = 0

    for right in range(len(arr)):
        # Step 1: Expand — add arr[right] to window
        # ... update window_state with arr[right] ...

        # Step 2: Shrink — while constraint violated, move left
        while not constraint_satisfied(window_state):
            # ... remove arr[left] from window_state ...
            left += 1

        # Step 3: Update answer
        best = max(best, right - left + 1)

    return best
```

# --- Problem 1: Max consecutive 1s with k flips ---
def max_ones_with_k_flips(nums, k):
    """Find longest subarray of 1s if you can flip at most k zeros."""
    left = 0
    zeros_in_window = 0
    max_len = 0

    for right in range(len(nums)):
        if nums[right] == 0:
            zeros_in_window += 1

        # Too many zeros — shrink from left
        while zeros_in_window > k:
            if nums[left] == 0:
                zeros_in_window -= 1
            left += 1

        max_len = max(max_len, right - left + 1)

    return max_len

# --- Problem 2: Minimum window substring ---
def min_window_substring(s, t):
    """Find smallest window in s containing all chars of t."""
    if not t or not s:
        return ""

    need = defaultdict(int)
    for c in t:
        need[c] += 1

    have, required = 0, len(need)
    window = defaultdict(int)
    left = 0
    best = (float('inf'), 0, 0)  # (length, left, right)

    for right, c in enumerate(s):
        window[c] += 1
        if c in need and window[c] == need[c]:
            have += 1

        while have == required:
            if (right - left + 1) < best[0]:
                best = (right - left + 1, left, right)
            window[s[left]] -= 1
            if s[left] in need and window[s[left]] < need[s[left]]:
                have -= 1
            left += 1

    return s[best[1]:best[2]+1] if best[0] != float('inf') else ""

# --- Problem 3: Sliding window maximum ---
from collections import deque

def sliding_window_max(nums, k):
    """Find the maximum in each window of size k using a deque."""
    dq = deque()   # Stores indices, decreasing by value
    result = []

    for i, val in enumerate(nums):
        # Remove indices outside window
        while dq and dq[0] < i - k + 1:
            dq.popleft()

        # Remove smaller elements (they'll never be max)
        while dq and nums[dq[-1]] < val:
            dq.pop()

        dq.append(i)

        if i >= k - 1:
            result.append(nums[dq[0]])

    return result

print("\n=== Problem 3: Sliding Window Maximum ===")
nums = [1, 3, -1, -3, 5, 3, 6, 7]
k = 3
print(f"  nums={nums}, k={k}")
print(f"  maxima = {sliding_window_max(nums, k)}")

## When to Use Sliding Window

> **Recognition Pattern**: The problem asks about a **contiguous subarray or substring**, with a constraint about its contents (sum, count of distinct elements, frequency). If you see that, think sliding window immediately.

| Problem Type | Window Style |
|---|---|
| Max/min subarray of size k | Fixed window |
| Longest substring without repeating chars | Dynamic — shrink on duplicate |
| Smallest subarray with sum ≥ target | Dynamic — shrink when constraint met |
| Max consecutive 1s with k replacements | Dynamic — shrink on excess replacements |
| Minimum window substring | Dynamic — shrink when all chars found |

> **Pro Tip:** The key to dynamic sliding window is identifying your **invariant** — the property that must always hold about your window. Make the `while` condition exactly that invariant violation. The window is always valid when you update the answer.

> **Common Mistake:** Using `for left in range(...)` inside the outer `for right` loop — that's O(n²) again. The left pointer must **only ever move forward**, never reset. Both pointers together traverse the array at most once — that's how you get O(n).
