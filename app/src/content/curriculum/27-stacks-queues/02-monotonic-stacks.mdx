# Monotonic Stacks: The O(n) Pattern for Range Queries

A **monotonic stack** is a stack that maintains its elements in strictly increasing or decreasing order. Whenever a new element would violate the order, you pop until the order is restored. This seemingly simple invariant solves an entire family of interval problems in O(n) that would otherwise require O(n²).

## The Core Pattern: Next Greater Element

**Problem**: For each element in an array, find the next element to its right that is greater.  
**Brute force**: O(n²) — nested loops.  
**Monotonic stack**: O(n) — single pass.

```python
def next_greater_element(nums):
    n = len(nums)
    result = [-1] * n
    stack = []   # Stores indices, maintains DECREASING values

    for i in range(n):
        # Pop all elements smaller than current — current is their answer
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()
            result[idx] = nums[i]
        stack.append(i)

    return result   # Remaining in stack have no greater element → -1

# Trace on [2, 1, 5]:
# i=0: push 0. stack=[0]
# i=1: nums[0]=2 > nums[1]=1. push 1. stack=[0,1]
# i=2: nums[1]=1 < 5 → pop 1, result[1]=5. nums[0]=2 < 5 → pop 0, result[0]=5. push 2.
# Result: [5, 5, -1]
```

## Decreasing vs Increasing Stacks

| Stack Type | Maintains | Solves |
|---|---|---|
| **Decreasing** | Larger values at bottom | Next Greater Element |
| **Increasing** | Smaller values at bottom | Next Smaller Element |

```python
def next_smaller_element(nums):
    n = len(nums)
    result = [-1] * n
    stack = []   # INCREASING stack

    for i in range(n):
        while stack and nums[stack[-1]] > nums[i]:  # Note: > not <
            idx = stack.pop()
            result[idx] = nums[i]
        stack.append(i)

    return result
```

## Largest Rectangle in Histogram

The canonical hard problem solved by monotonic stack: find the largest rectangle that can be formed in a histogram.

```python
def largest_rectangle(heights):
    stack = []   # Increasing stack of indices
    max_area = 0
    heights = heights + [0]   # Sentinel: force flush at end

    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)

    return max_area
```

## When to Use Monotonic Stacks

> **Recognition**: The problem asks about the **next/previous greater/smaller element** for each position, or about the **maximum rectangle/area** under constraints. Any problem where you need to efficiently find "the nearest element satisfying a condition" in O(n) likely uses a monotonic stack.

| Problem | Stack Direction |
|---|---|
| Next Greater Element | Decreasing stack |
| Next Smaller Element | Increasing stack |
| Previous Greater Element | Decreasing stack (traverse right to left) |
| Largest Rectangle in Histogram | Increasing stack |
| Trapping Rain Water | Two approaches: monotonic stack or two pointers |
| Daily Temperatures | Decreasing stack |

> **Pro Tip:** The "pop while violating" pattern has O(n) total time even though it has a nested while loop. Each element is pushed exactly once and popped at most once — amortized O(1) per element, O(n) total.

> **Common Mistake:** Storing values instead of indices in the stack. You almost always need the index to compute distances or fill the result array at the correct position. Store indices; access values via `nums[stack[-1]]`.
