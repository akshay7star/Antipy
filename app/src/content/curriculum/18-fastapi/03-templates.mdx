# FastAPI Templates (Jinja2)

While FastAPI's true superpower is building blazingly fast JSON APIs for frontend frameworks (like React, Vue, or iOS apps), you don't *have* to use a separate frontend.

FastAPI fully supports Server-Side Rendering (SSR) using **Jinja2**, the exact same templating engine used by Flask. 

Because FastAPI is un-opinionated about the frontend, it doesn't include Jinja2 out of the box. You must install it manually alongside your FastAPI installation.

```bash
# Install Jinja2 explicitly
$ pip install jinja2
```

## Configuring Jinja2 in FastAPI

In Flask, templates just work "magically" if you put them in a `templates/` folder. Because FastAPI is explicit, you have to tell it where your templates are located and create a `Jinja2Templates` object.

<interactive-code>
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates
from fastapi.responses import HTMLResponse

app = FastAPI()

# 1. Point FastAPI to the directory containing your HTML files
templates = Jinja2Templates(directory="templates")

# 2. Tell FastAPI this route returns an HTMLResponse (not JSON)
@app.get("/", response_class=HTMLResponse)
async def read_item(request: Request):
    # 3. Render the template, passing the Request object and context data
    return templates.TemplateResponse(
        request=request, 
        name="index.html", 
        context={"username": "Alice"}
    )
</interactive-code>

### Why `Request`?
Notice that we had to pass `request: Request` into the function, and then pass `request=request` into the `TemplateResponse`. 

Jinja2 requires the HTTP request object to generate absolute URLs, manage sessions, and handle certain security features. In Flask, this is hidden from you. In FastAPI, "Explicit is better than implicit."

## Using Jinja2 Syntax

The HTML files you write for FastAPI are **100% identical** to the ones you write for Flask. You still use `{{ variable }}`, `{% for %}`, and `{% extends %}`.

```html
<!-- Inside templates/index.html -->
<html>
  <head>
    <title>FastAPI SSR</title>
  </head>
  <body>
    <h1>Welcome to FastAPI, {{ username }}!</h1>
    
    {% if is_admin %}
      <p>You have administrative privileges.</p>
    {% endif %}
  </body>
</html>
```

## Serving Static Files

A website isn't just HTML; it needs CSS, JavaScript, and images. Just like templates, FastAPI requires you to explicitly "mount" a directory to serve static files.

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# "Mount" the local directory named "static" to the URL path "/static"
app.mount("/static", StaticFiles(directory="static"), name="static")
```

Once mounted, you can link to a CSS file in your HTML template just like you would in Flask:

```html
<!-- Inside your Jinja2 template -->
<link href="{{ url_for('static', path='/css/styles.css') }}" rel="stylesheet">
```
