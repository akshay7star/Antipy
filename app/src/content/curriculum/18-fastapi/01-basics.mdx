# FastAPI Basics

Flask is simple. Django is comprehensive. **FastAPI** is modern, blazingly fast, and deeply intelligent. 

FastAPI was built from the ground up to utilize modern Python features—specifically **Type Hints** and **Asynchronous Programming** (`async`/`await`). Because it forces you to declare strict data types for all your inputs and outputs, it provides two massive superpowers out of the box:
1. Automatic data validation (it rejects bad requests for you).
2. Automatic, interactive API documentation (Swagger UI).

## Hello World in FastAPI

FastAPI looks incredibly similar to Flask on the surface.

<interactive-code>
from fastapi import FastAPI
import uvicorn

app = FastAPI()

@app.get("/")
def read_root():
    # FastAPI automatically converts Python dictionaries to JSON!
    return {"message": "Welcome to FastAPI"}

# You run it using an ASGI server like uvicorn:
# if __name__ == "__main__":
#     uvicorn.run(app, host="0.0.0.0", port=8000)
</interactive-code>

Notice we used `@app.get("/")` instead of Flask's generic `@app.route("/")`. FastAPI explicitly separates HTTP methods (`@app.get`, `@app.post`, `@app.put`, `@app.delete`) at the decorator level for cleaner code.

## Automatic API Documentation

When you build an API for a frontend developer (or a mobile app developer), they need to know what URLs exist and what data they return. 

Historically, developers had to manually write massive Google Docs or Wiki pages explaining their APIs.

With FastAPI, you simply visit `http://127.0.0.1:8000/docs`. FastAPI automatically generates a beautiful, interactive web interface (Swagger UI) that lets anyone explore and test your API right from the browser. It reads your Python code and builds the documentation for you!

## Type Validation with Pydantic

The real magic of FastAPI comes from its integration with **Pydantic**. 

Instead of manually checking if a user submitted a valid email or if their age is an integer, you simply define a Pydantic model (a standard Python class with type hints).

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

# 1. Define what the incoming JSON should look like
class Item(BaseModel):
    name: str
    price: float
    is_offer: bool = None # Optional field

# 2. Use the class as a type hint in your route!
@app.post("/items/")
def create_item(item: Item):
    # If the user sends a string for 'price', FastAPI automatically 
    # intercepts it and returns a 422 Validation Error BEFORE 
    # this function even runs!
    
    # You get full autocomplete here in your IDE!
    return {"item_name": item.name, "item_price": item.price}
```

## ASGI: Built for Speed

Flask and Django were originally built on **WSGI** (Web Server Gateway Interface), which is synchronous. It handles one request at a time per worker.

FastAPI is built on **ASGI** (Asynchronous Server Gateway Interface). It natively supports Python's `async def` and `await` keywords, allowing a single worker to handle thousands of simultaneous connections (like WebSockets) without blocking. This makes FastAPI's performance rival NodeJS and Go.
